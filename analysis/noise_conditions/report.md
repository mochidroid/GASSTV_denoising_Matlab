# ノイズ条件ごとのスペクトルグラフ比較 (分析レポート)

- 対象: GASSTV のスペクトルグラフ 5 通り (omega0 / baseline / p2_mknn / p2_mknn_ns / p2_eps) と既存法 4 手法 (SSTV, HSSTV_L1, HSSTV_L12, l0l1HTV)。rho = 0.95, lambda_rho_sp = 0.8, sigma_sp = "90"。
- 再現: `uv run analysis/noise_conditions/analyze_noise_conditions.py`。全部の表は [tables.md](tables.md)、元データは同じフォルダの CSV。
- 新しい実験は回していない。

## 0. 結論の要約

- **p2_mknn (案2, mutual kNN k=60, h=1, 符号あり) を採用するのが妥当。** 理由は次の 3 つ。
  - 最良 ω どうしで baseline に負けた条件が無い (12 勝 / 2 分 / 0 負、平均 +0.065 dB)。
  - 同じ ω どうしでは、ω ≥ 100 の 14 組すべてで baseline を上回る。
  - 全条件で共通の ω を 1 つ使う比較でも、平均 MPSNR が最も高い (ω=100 で 36.904 dB、baseline は ω=30 で 36.848 dB)。
- ただし、baseline との差が 0.05 dB を超えたのは 14 組中 4 組 (J3, J7, P7, P9) だけ。**残り 10 組は有意差なし**として扱う。
- 条件 1・8 は GASSTV 系の結果が無い。条件 9 は、デッドラインをスパースの項に入れる前の式 (旧式) で計算した結果である (5 節)。

## 3. 現行グラフとの比較 (3.2)

### 事実: 最良 ω どうしの差 (比較対象 − baseline)

| 比較対象 | ΔMPSNR 平均 / 最小 / 最大 (14 組) | 勝 / 分 / 負 (±0.01 dB) | ΔSAM 平均 / 最小 / 最大 |
|---|---|---|---|
| omega0 | -0.354 / -0.867 / +0.042 | 2 / 0 / 12 | +0.140 / -0.075 / +0.583 |
| p2_mknn | +0.065 / +0.001 / +0.210 | 12 / 2 / 0 | +0.056 / -0.203 / +0.818 |
| p2_mknn_ns | -0.009 / -0.308 / +0.145 | 6 / 4 / 4 | +0.012 / -0.185 / +0.334 |
| p2_eps | +0.009 / -0.309 / +0.444 | 8 / 1 / 5 | +0.011 / -0.124 / +0.231 |

- p2_mknn の ΔMPSNR が 0.05 dB を超えたのは J3 (+0.210)、J7 (+0.140)、P7 (+0.199)、P9 (+0.143) の 4 組だけ。他の 10 組は +0.001〜+0.048。
- p2_mknn の SAM:
  - PaviaU: 7 組すべてで baseline 以下 (−0.001〜−0.203)。
  - JasperRidge: J3 (+0.818)、J7 (+0.407)、J5 (+0.069)、J9 (+0.025) で悪化。J3 と J7 は MPSNR が最良になる ω (300 と 100) で SAM が悪化している。
- p2_eps: 最も大きく改善した組 (J7 +0.444) と、最も大きく悪化した組 (P5 −0.309) がどちらもある。ストライプのみの条件 (4, 5) では、両画像とも baseline より悪い (−0.073〜−0.309)。

### 事実: 同じ ω どうしの差 (p2_mknn − baseline, 両画像 14 組)

| ω | 平均 / 最小 / 最大 | 勝 / 分 / 負 |
|---|---|---|
| 10 | +0.011 / -0.015 / +0.046 | 8 / 4 / 2 |
| 30 | +0.025 / -0.008 / +0.078 | 11 / 3 / 0 |
| 100 | +0.057 / +0.011 / +0.143 | 14 / 0 / 0 |
| 300 | +0.106 / +0.015 / +0.340 | 14 / 0 / 0 |
| 1000 | +0.179 / +0.019 / +0.613 | 14 / 0 / 0 |

図: [fig_delta_per_omega.png](fig_delta_per_omega.png)

- p2_mknn_ns は、JasperRidge では ω ≥ 100 の 7 組すべてで baseline に負ける。PaviaU ではほぼすべてで勝つ。
- p2_eps は、JasperRidge で ω を大きくするほど差が開く (ω=1000 で平均 +0.388)。PaviaU では平均 −0.024 で、組によって ±0.6 dB までばらつく。

### 解釈

- p2_mknn は、どの ω でも baseline と同等以上。差は ω が大きいほど広がる。小さい ω (10〜30) では差がほぼ 0 なので、最良 ω が小さい条件では最良どうしの差も小さくなる。
- p2_eps の平均がほぼ 0 なのは、条件によって大きく良くなる組と大きく悪くなる組が打ち消し合っているため。設定として安定していない。

## 4. omega への頑健性 (3.3)

図: [fig_omega_curves.png](fig_omega_curves.png) (横軸 ω、縦軸 MPSNR。灰色の破線が omega0)

### 事実

| 比較対象 | 劣化 (最良 − ω=1000) 平均: J / P / 両画像 | 劣化 最大 | 良好域 (最良から 0.1 dB 以内の ω の数) 平均 |
|---|---|---|---|
| baseline | 0.934 / 0.378 / 0.656 | 1.408 | 2.07 |
| p2_mknn | 0.767 / 0.318 / 0.542 | 1.168 | 2.00 |
| p2_mknn_ns | 1.292 / 0.333 / 0.813 | 1.767 | 2.00 |
| p2_eps | 0.597 / 0.371 / 0.484 | 1.083 | 2.07 |

- p2_mknn の劣化は、14 組中 12 組で baseline より小さい。残る P3 (0.072 対 0.069) と P7 (両方とも最良が ω=1000 で 0) は同等。
- p2_eps の劣化が baseline より小さいのは、JasperRidge では 7 組中 5 組 (例外: J4 と J5)、PaviaU では 7 組中 2 組 (P2, P9)。P3, P4, P5, P6 では baseline より大きい。
- 良好域の幅は、どの比較対象でも平均 2 個前後 (5 個中) で、差は無い。

### 解釈

- 「ω=1000 での落ち込みが小さい」という意味の頑健性は、p2_mknn では両画像で成り立つ。p2_eps では JasperRidge だけで成り立つ。
- ω 格子が 3 倍刻みで粗いので、良好域の幅ではほとんど差がつかない。

## 10. 注意点

- **ノイズの実現は 1 通りだけ** (dataset/ の観測、MATLAB の `rng("default")`)。0.05 dB 未満の差は有意とみなさない。p2_mknn の baseline に対する勝ち 12 組のうち、8 組はこの範囲に入る。
- **条件 9 は計算に使った式が現行コードと違う。** GASSTV 系 (eps_graph) と既存法 (result/) の条件 9 は、どちらもデッドラインをスパースの項に含めない旧式の alpha で計算した。両者の式は揃っているので比較は成り立つが、現行コードで回し直すと値が変わる。
- 条件 8 の既存法は、過去の実験から取り込んだものだけ。これは現行の式で計算されている。HSSTV の `o0.01` が無いので、「最良」は 2 設定から選んだもの。
- l0l1HTV の `sr0.9999` は全条件で最大反復 (20000) に達していて、停止条件で収束していない。
- ω の最良が格子の端にある組 (J2, J6, J9 は下端、P7 は上端) がある。
- 図の配色は、dataviz スキルの基準パレットの先頭 4 色を固定順で使い、マーカーの形も変えた。このマシンには node が無く、パレット検証スクリプトは実行していない。
